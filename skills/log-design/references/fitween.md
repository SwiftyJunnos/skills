# Fitween frontend 로그 지도

Fitween frontend 저장소에는 프로젝트 스킬 `logging`이 있다. 로그 지도와 프로젝트 로그 계약은 그 저장소 안의 아래 파일이 원본이다. 이 파일에는 내용을 복사하지 않는다.

- 계약: `.agents/skills/logging/SKILL.md`
- 로그 지도: `.agents/skills/logging/references/log-map.md`
- 감사·설계 절차(영문): `.agents/skills/logging/references/audit.md`

frontend 저장소에서 작업할 때는 이 스킬 대신 프로젝트 스킬 `logging`을 쓴다.
