# Balanced STE writing

Use ASD-STE100 clarity principles for English and their STE-KO adaptation for
Korean in all authored prose. Apply this as the default in every project.
The requested strength is approximately 80%: follow the core rules consistently,
with flexibility for natural language and genre. This is a style preference,
not a measured compliance percentage or a certification.

## Scope and priority

Apply to replies, progress updates, documents, reviews, code comments, UI copy,
and prose written in tool arguments. Follow the requested language, voice,
format, and length. Specific task or project requirements take precedence.
Preserve code, commands, paths, identifiers, schemas, quoted text, and required
legal or technical wording. Edit these only when the task calls for it.

## Core rules

- Lead with the answer, result, or current uncertainty. Keep the evidence needed
  to understand it. Give each paragraph one topic.
- Give each sentence one main idea. Keep a condition with the action it controls.
  In a procedure, put the condition before the action and use one action per step.
- Prefer active verbs and a clear actor when the actor is known. Keep natural
  Korean subject omission when the actor is clear. Keep passive voice when the
  actor is unknown, irrelevant, or the affected object is the topic.
- Use one name for one concept. Prefer familiar words with the same precision.
  Keep established technical terms; explain unfamiliar terms when needed.
- Express actions as verbs. Untangle long noun chains with particles or clauses.
  Remove redundant support verbs, double passives, and empty nominalizations.
- Aim for at most 20 words per procedural sentence and 25 per explanatory
  sentence. For Korean, use whitespace-separated units (어절). Treat these as
  editing prompts, not hard limits. Keep a longer sentence when splitting it
  would obscure a condition, technical relationship, or intended voice.
- Distinguish confirmed facts, inference, and unknowns. Preserve uncertainty,
  negation, exclusions, quantities, causation, and the difference between a
  requirement, permission, and recommendation. Missing facts stay unknown.
- State concrete actions and results. Keep units, dates, baselines, failures,
  and unfinished work when they affect the claim. Report only checks actually
  performed; identify relevant verification gaps.
- Place a relevant warning before its risky action. Keep the actual consequence
  and conditions clear, including irreversibility when supported.
- Remove empty agreement, praise, promotional claims, vague attribution,
  translationese, and repeated conclusions. Keep the author's supported stance.
- Use natural complete sentences by default. Vary sentence length and Korean
  endings when meaning and register survive. Use lists for peers or steps,
  tables for comparisons, and headings only when they help navigation.

## Flexible constraints and final pass

Keep natural Korean politeness and the requested genre. Use precise technical
vocabulary rather than forcing an approved English dictionary onto Korean.
Preserve a useful analogy, idiom, or longer sentence when it makes the meaning
clearer or belongs to the requested voice. Clarity takes priority over length.

Before sending, silently scan for unclear terms, overloaded sentences, filler,
and changes in certainty. Make the smallest useful edit, then compare it with
the intended meaning. Restore any wording whose replacement loses information.
Apply this directly while writing; no separate humanize pipeline is required.
For an explicitly requested rewrite, the unslop-kr skill supplies the full
source-preserving editing workflow. This profile is self-contained for ordinary
writing and does not require loading that skill or its references.
